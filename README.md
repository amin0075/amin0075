Hey, I'm Amin. I'm a full-stack software engineer in Chester, UK, and I've been building web apps for 6+ years, mostly React and Next.js up front, Node and Postgres behind it, and more and more AI features lately.

By day I'm a frontend engineer at Keystone Education Group, where I've shipped an analytics dashboard for institutions and an AI advisor that helps students find the right course on educations.com.

I also make short videos as **@amin_decods**. Each one takes an everyday job in a TypeScript, React or Next.js project and shows a better way to do it with an agent: the setup, the exact prompt, and what you actually get.
